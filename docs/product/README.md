## Что есть сейчас

Реализованы локальная драматургическая мастерская, документы → ТЗ → варианты, проверки и редактура. В новой итерации — обзор всего маршрута и версионные локальные копии с защитой от конфликтов. E14-US01 и E15-US01 стоят In Review. Серверная история копий доступна через API; отдельный браузер истории SQLite ещё не реализован.

Командная авторизация, Postgres, сцены/планы/ассеты как серверная предметная модель, видео, цвет и таймлайн описаны и разбиты на задачи. Их наличие в документации не означает работающую функцию.

## Как работать

Открыть недельную веху → взять конкретную историю → проверить критерий и зависимости → связать PR → показать на проекте Anix → принять. Эпик закрывается после приёмки историй. Только S01 детализирован как ближайшая очередь; остальные недели — плановая последовательность, а не обещание срока.

Сцена, план, видео-дубль и монтажный фрагмент — разные сущности. Любое согласование относится к точной ревизии. Правки создают новую версию и явно показывают устаревшие зависимости.
